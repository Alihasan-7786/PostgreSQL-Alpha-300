# PostgreSQL Alpha 300

This repository contains all my practice work and notes from the Udemy PostgreSQL course I am currently learning.

I created this repository to keep track of what I learn, practice SQL queries, and understand how databases work through hands-on examples.

## What I'm Learning

Throughout this course, I am learning and practising topics such as:

- SQL basics and database creation
- Creating and modifying tables
- INSERT, UPDATE, DELETE and SELECT queries
- Primary keys and foreign keys
- Different types of database keys
- Database normalization (1NF to 5NF)
- Entity Relationship (ER) diagrams
- Relationships between tables
- SQL Joins (INNER, LEFT, RIGHT, CROSS and SELF JOIN)
- Database design using DBML
- Connecting PostgreSQL with JavaScript using Node.js

## What's Inside This Repository?

You will find:

- `.sql` files – Queries and exercises that I practise during the course.
- `.dbml` files – Database structures and relationship diagrams.
- `.js` files – JavaScript examples related to PostgreSQL.
- `notes.md` – My notes and important concepts from the course.

I have organized the files according to the course sections so that I can easily find and revise topics whenever needed.
